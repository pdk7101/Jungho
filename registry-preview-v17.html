v17 개발 화면 · 기본은 메모리 전용 테스트입니다. 검증된 개발 Worker에 연결하면 종목 목록을 공유합니다. 실제 보유기록은 변경하지 않습니다.

개발용 Cloudflare 연결

연결 대상은 본인의 v17 전용 서버입니다. 토큰은 저장하지 않으며 새로고침 시 재입력해야 합니다.

오프라인 미리보기

개발용 KRX 공식 종가 연결

기존 KRX 인증을 사용하는 격리 개발 Worker만 연결하세요. 조회할 때만 공식 일별 자료를 요청합니다. 당일 종가나 실시간 가격이 아닙니다.

미연결

신규 종목 등록

화면 초기화 중

등록은 감시 대상의 미리보기이며 매수 주문이 아닙니다. 종목코드 형식 확인과 실제 거래 가능 확인은 별개입니다.

신규 투자기록 영구 저장 (개발용)

등록 서버 연결 후 별도 POSITION_RECORD_TOKEN으로 신규 종목 수량·평단·누적 세후 분배금을 비공개 저장합니다. 기존 운영 계좌 기록은 수정하지 않습니다. 다른 기기에서 변경한 기록은 다시 조회하여 확인해야 합니다.

미연결 · 오프라인 테스트 기록은 저장되지 않습니다.

공통 미국 종목 참고환율

기존 미국 일봉 파일의 공개 참고환율을 자동 사용합니다. 직접 입력은 선택 사항입니다. 모든 미국 종목에 같은 환율을 적용하되 실시간 환율이나 증권사 적용 환율이 아닙니다. 실제 계좌 기록과 분리된 테스트이며 새로고침·연결 전환 시 입력 기록이 초기화될 수 있습니다.

참고환율 확인 대기

전체 계좌 통합 참고 평가 (개발용)

같은 출처에 저장된 기존 직접 입력 기록만 읽습니다. 증권사 잔고, 과거 사진, 계좌 수동 합계와는 다를 수 있습니다. 전체 최신 잔고임을 확인하지 않으면 합계를 확정하지 않습니다. 기존 배당 합계와 신규 누적 배당의 중복 여부가 미확인이므로 통합 배당 합계는 보류합니다.

기존 기록 미확인

신규 종목만의 계좌별 합계

기존 계좌 총액에 더하지 않습니다. 시세·원금 미확인 시 해당 합계는 미확인으로 표시합니다. 분배금은 평가손익과 별도입니다.

계좌별 종목

기존 목록은 v16 등록 목록 기준입니다. 실제 잔고가 아닙니다. 미연결 테스트 등록은 메모리에만 남고, 연결 상태에서는 서버 확인 후 등록됩니다.

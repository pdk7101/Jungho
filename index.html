토스증권 공식 계좌 자동 조회 · 휴대폰/노트북 공용

본인 전용 HTTPS 조회 서버에서 토스증권 공식 API를 호출합니다. 공식 조회 성공 시 마지막 잔고를 이 기기에 자동 저장합니다. 노트북이 꺼져도 저장 당시의 수량·평가액과 조회일을 볼 수 있지만 최신 잔고로 갱신되지는 않습니다. 어제 날짜의 값은 어제 실제 조회한 기록이 있을 때만 사용됩니다. 토스 Client ID·Client Secret을 이 화면이나 공개 GitHub에 입력하지 마세요. 계좌 조회만 지원하며 매매 주문은 하지 않습니다.

규모·NAV 데이터 확인 중

5일·20일 증감은 이 앱이 저장한 실제 거래일별 스냅샷이 6개·21개 쌓인 후에만 표시합니다. 시장가격과 NAV의 기준 시점이 다를 수 있으며, 해외자산 ETF는 괴리율 해석에 특히 주의가 필요합니다. 괴리율·유동성 경고는 보조 확인 신호이며 기존 매수 상한과 수량을 자동 변경하지 않습니다.

종목별 차트 · 종가 / 5일선 / 20일선
KODEX 200TR 감시 기준 · 하루 예산 설정
박스권 하단 30%는 저가 관심, 하단 20%는 더 낮은 저가 우선 검토구간입니다. 평단가보다 낮더라도 하락 추세가 지속될 수 있으며, 매수 상한과 예산 조건을 우선합니다.

리츠·SOL 조건별 수량은 위의 ‘국내 ETF 매수계획’에 표시합니다. SOFR 월요일 1주와 KODEX 200TR -5% 감시는 유지하며, 실제 키움 주문은 자동 변경하지 않습니다.

가격·주문 안내

국내 ETF 가격과 지표는 KRX 공식 일별매매정보의 마지막 검증된 거래일 기준입니다. 실시간 체결가가 아니며 KRX API 키 또는 이용 승인이 없으면 확인 대기 상태로 표시합니다. 주문 전 키움증권에서 확인하세요. 이 프로그램은 자동주문·앱 종료 후 푸시 알림을 지원하지 않으며 보유정보는 현재 브라우저에만 저장합니다.
